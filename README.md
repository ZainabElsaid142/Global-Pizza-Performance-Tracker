## 💡 The Analytical Workflow

### Phase 1: SQL Data Ingestion & Querying
I didn't just import the CSV; I built a robust database. I created tables, ensured proper data types, and wrote complex SQL queries to extract meaningful insights.

**Key SQL Techniques used:**
*   **JOINs:** To aggregate disparate data points.
*   **Data Grouping:** Using `GROUP BY` to identify trends.
*   **Aggregation:** Calculated total revenue, order counts, and performance metrics directly within SQL.

### Phase 2: Schema & Data Modeling
Using the schema structure, I built a relational model in Power BI. I established relationships between the main `pizza_sales` table and the analytical `Views` I created in SQL, ensuring high performance and dashboard interactivity. 

*   **DAX Implementation:** Added dynamic date dimension columns (`Month_Name`, `Order_day`) to bridge the gap between static tables and time-based insights.
*   **Relationship Management:** Configured "Both" cross-filter directions to enable global slicer interactivity across the entire dashboard.

### Phase 3: Visual Analytics
The dashboard is designed for high-impact decision-making:
*   **KPI Cards:** Instant access to Revenue, Avg Order Value, and Total Sold.
*   **Trend Analysis:** Interactive area charts for daily and monthly performance.
*   **Composition:** Donut charts breaking down sales by category and size.

## 📈 Key Insights & Business Value
*   **Optimization:** Identified peak hours and days, enabling staff optimization.
*   **Product Performance:** Categorized top and bottom-performing pizzas, driving inventory focus.
*   **Data-Driven Growth:** The dashboard provides a clear roadmap for marketing and operational adjustments.
